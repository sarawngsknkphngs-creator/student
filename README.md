# ระบบรับสมัครเรียนออนไลน์ครบวงจร (Online Student Admission System)
**วิทยาลัยอาชีวศึกษา ประจำปีการศึกษา 2568**
ต่อยอดจาก Google Forms + Google Sheets + AutoCrat สู่ระบบสารสนเทศสถานศึกษามาตรฐาน เชื่อมโยงฐานข้อมูล ศธ.02

---

## 🌟 ฟังก์ชันหลักของระบบ

### 1. ส่วนสำหรับผู้สมัครเรียน (Front-end)
1. **ระบบกรอกใบสมัครและการตรวจสอบความถูกต้อง (Data Validation):**
   - ตรวจสอบความถูกต้องของเลขประจำตัวประชาชน 13 หลัก ด้วยสูตร **Modulus 11 Checksum** ทั้งฝั่ง Client และ Server ป้องกันการกรอกเลขมั่ว
   - ตรวจสอบรูปแบบเบอร์โทรศัพท์ 10 หลัก
   - Cascading Dropdown เลือกระดับชั้น (ปวช./ปวส.) และดึงสาขาวิชาที่เปิดรับตามระดับชั้นอัตโนมัติ ลดปัญหาพิมพ์ชื่อสาขาผิด
2. **ระบบอัปโหลดเอกสารหลักฐาน:**
   - แนบรูปถ่ายหน้าตรง (1-1.5 นิ้ว), สำเนาบัตรประชาชน, สำเนาทะเบียนบ้าน และใบแสดงผลการเรียน (รบ./ปพ.1)
   - ตรวจสอบประเภทไฟล์ (JPG, PNG, PDF) และจำกัดขนาดไม่เกิน 5MB พร้อมพรีวิวรูปถ่ายทันทีก่อนกดยื่น
3. **ระบบตรวจสอบสถานะการสมัคร (Status Tracking):**
   - ค้นหาด้วยเลขบัตรประชาชน 13 หลัก
   - แสดง Timeline ขั้นตอนการสมัคร (ส่งใบสมัคร -> ตรวจสอบเอกสาร -> ผ่านการคัดเลือก -> มอบตัว)
   - หากเอกสารไม่ครบหรือมีข้อผิดพลาด จะมีข้อความแจ้งเตือนจากเจ้าหน้าที่ พร้อมช่องให้อัปโหลดเอกสารแก้ไขได้ทันทีโดยไม่ต้องกรอกข้อมูลใหม่
4. **ระบบสร้างและดาวน์โหลดเอกสารอัตโนมัติ (PDF Engine ทดแทน AutoCrat):**
   - **ใบสมัครเข้าศึกษาต่อ (PDF):** ฟอนต์ภาษาไทยมาตรฐาน Sarabun ขนาด A4 พร้อมติดรูปถ่ายและ QR Code สำหรับสแกนเช็กสถานะ
   - **ใบมอบตัวและสัญญาการเป็นนักศึกษา (PDF):** พร้อมพิมพ์เงื่อนไข ข้อตกลง และช่องลงลายมือชื่อผู้ปกครองและพยาน

---

### 2. ส่วนสำหรับเจ้าหน้าที่และผู้ดูแลระบบ (Back-end)
1. **ระบบจัดการและตรวจสอบข้อมูลผู้สมัคร (Admin Verification):**
   - ตารางรายชื่อผู้สมัคร กรองตามระดับชั้น (ปวช./ปวส.), สาขาวิชา, และสถานะการสมัคร
   - หน้าตรวจสอบเอกสารแบบ Inline Document Previewer (ดูรูปถ่ายและ PDF ได้ทันทีในหน้าเว็บ)
   - ปุ่มเปลี่ยนสถานะ (รอตรวจ, เอกสารไม่ครบ, ผ่านการคัดเลือก, มอบตัวแล้ว, ไม่ผ่าน) พร้อมช่องระบุหมายเหตุ
2. **ระบบแจ้งเตือนอัตโนมัติ (LINE Notification):**
   - ส่งแจ้งเตือนเมื่อมีผู้สมัครใหม่เข้ามา
   - ส่งแจ้งเตือนผู้สมัครเมื่อเจ้าหน้าที่ปรับปรุงสถานะหรือแจ้งให้แก้ไขเอกสาร
3. **ระบบออกรหัสประจำตัวและจัดการมอบตัว (Enrollment System):**
   - กำหนดรหัสนักศึกษาให้อัตโนมัติ (Auto-generate) ตามรูปแบบ ศธ. เช่น `68201010001`
   - บันทึกชื่อผู้ปกครองที่มามอบตัว, วันที่มอบตัว, พยานฝ่ายสถานศึกษา และสถานะค่าธรรมเนียม
4. **แดชบอร์ดสรุปสถิติแบบเรียลไทม์ (Real-time Analytics Dashboard):**
   - กราฟสรุปยอดผู้สมัครแยกตามสาขาวิชา เทียบกับโควตารับ
   - แผนภูมิสัดส่วน ปวช. vs ปวส.
   - จัดอันดับ 10 โรงเรียนเดิมที่ส่งนักเรียนมามากที่สุด (Top Feeder Schools)
   - สถิติตามช่องทางการรับรู้และผลงานครูแนะแนว
5. **ระบบส่งออกข้อมูลรองรับ ศธ.02 (Export Data):**
   - ส่งออกเป็นไฟล์ **Excel (.xlsx)** จัดหัวตาราง สี และลำดับคอลัมน์ตรงตามโครงสร้างของงานทะเบียน ศธ.02
   - ส่งออกเป็นไฟล์ **CSV** เข้ารหัส UTF-8 BOM สำหรับเปิดใน Microsoft Excel ได้ทันทีโดยภาษาไทยไม่เพี้ยน
